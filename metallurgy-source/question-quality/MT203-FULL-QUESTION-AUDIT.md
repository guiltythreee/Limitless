## Cross-topic engineering findings

1. MT203 assertion–reason adapter fallback uses a literal escaped newline, so normalized stem contains literal \\\\n rather than a real line break. The adapter test expects that literal sequence and preserves the defect. Fix adapter and test for an actual newline.
2. MT203 profile currently registers only single-choice, while adapter maps numerical, assertion–reason, matching, sequence, graph and other formats. Add format-specific profiles/rules; mapping is not validation.
3. Structural validation does not establish scientific correctness, unique defensible answers, numerical validity, distractor quality or source alignment.
4. Many questions explain only one or two distractors. Add option-level rationales for reasoning questions; concise treatment can remain for simple recall.
5. Verify course-specific historical claims, empirical constants and industrial market-share figures against original module materials.
