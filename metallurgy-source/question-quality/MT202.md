# MT202 adapter

The MT202 adapter is a read-only projection from the existing chapter JSON format
into the shared question-quality contract.

Native taxonomy is retained:
- A: single-correct
- B: statement-selection (the statements may have multiple truths, but the
  stored answer is one option containing the selected statement combination)
- C: assertion–reason
- D: match
- E: numerical
- F: true / false
- G: data reading

Stable IDs remain `chNN-qN`. Legacy difficulty stars remain on their native
three-level scale and are not silently converted to the five-level MCQ-QS scale.
The adapter retains statements, tables, traps, explanations and native type in
metadata. It does not edit source JSON, answer keys, chapter structure, or saved
attempt data.

The fixture test runs the shared structural validator against all 522 committed
MT202 records. Passing structural validation does not certify scientific
correctness; the existing expert review and question-quality overlay workflow
remains authoritative for content changes.
