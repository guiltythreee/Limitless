# MT201 adapter

The MT201 adapter provides a read-only normalized view of the Metallurgical Thermodynamics question bank. It does not rewrite chapter JSON, answer keys, stable IDs, or learner progress.

| Native type | Shared format | Records |
|---|---|---:|
| A | single-choice | 219 |
| B | statement-selection | 17 |
| C | assertion-reason | 13 |
| D | match | 3 |
| E | numerical | 112 |
| F | true-false | 15 |
| **Total** | | **379** |

Native type B stores a selected combination as one answer option, so it is represented as statement-selection rather than multiple-choice. Difficulty uses the source bank's four-level star scale (1–4), preserved without conversion. The adapter retains statements, table rows, traps, assertion/reason fields, and explanation variants in metadata.

The test reads every chapter listed in the committed MT201 index, checks indexed counts, unique `chNN-qN` IDs, answer mapping, profile validation, explanation presence, and native difficulty scale. This is structural validation only; it does not establish thermodynamic correctness.
