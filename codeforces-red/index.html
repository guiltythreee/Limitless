THE TRAINING PLAN

Your route from below 1200 to 2400

Long-term progression · adapt to results

Rating is an outcome, not the curriculum. Move forward when you can solve the relevant problem types consistently, explain your approach, and reproduce it under contest conditions. Time ranges are planning estimates, not guarantees.

Starting point: foundationsBuild reliable implementation and core problem-solving habits before pushing rating.
PHASE 01Below 1200

Foundations and consistency

Target: reach and stabilise at Pupil (1200).

  • C++ fluency: input/output, types, loops, functions, arrays, strings, vectors, sorting and binary search.
  • Complexity: estimate time and memory; recognise linear, n-log-n and quadratic solutions.
  • Core patterns: frequency counting, prefix sums, two pointers, simulation, greedy basics and brute force.
  • Math basics: divisibility, gcd/lcm, primes, parity, remainders and integer overflow.

Practice: mostly 800–1100 problems. Solve, upsolve, then re-solve without notes. Keep an error log for implementation mistakes and missed observations.

PHASE 021200–1399

Specialist toolkit

Target: Specialist (1400).

  • Greedy proofs: sorting-based choices, exchange arguments, invariants and counterexamples.
  • Binary search on answer; monotonic predicates and boundary-safe implementation.
  • Data structures: maps, sets, stacks, queues, priority queues and basic DSU.
  • Strings: frequency methods, hashing concepts and prefix-function basics.
  • Combinatorics: counting, permutations, combinations and modular arithmetic foundations.

Practice: 1000–1400 problems. Start timed sets; after each contest, upsolve every problem you had a realistic path to solve.

PHASE 031400–1599

Core algorithms and breadth

Target: Expert (1600).

  • Graphs: BFS, DFS, connected components, bipartite checks, topological sorting and shortest paths.
  • Dynamic programming: state design, transitions, base cases, knapsack patterns, LIS and grid DP.
  • Number theory: sieve, prime factorisation, modular exponentiation, inverses and gcd reasoning.
  • Data structures: Fenwick tree, segment tree fundamentals and DSU applications.
  • Constructive problems: derive operations, maintain invariants and test edge cases.

Practice: 1200–1600 problems. Study one topic at a time, then mix topics so you learn to identify the technique without a label.

PHASE 041600–1899

Advanced reasoning

Target: Candidate Master (1900).

  • DP optimisation and less obvious state representations; bitmask DP where appropriate.
  • Advanced graph techniques: Dijkstra variants, SCC, bridges and articulation points.
  • Combinatorics: inclusion–exclusion, pigeonhole principle, expected value basics and counting arguments.
  • Range queries and updates: segment tree variants, lazy propagation and offline processing.
  • Harder greedy, constructive reasoning and implementation-heavy tasks.

Practice: 1500–1900 problems. Spend more time on editorials and proofs; reconstruct solutions from the key observation rather than memorising code.

PHASE 051900–2399

Mastery and contest depth

Targets: Master (2100), then International Master (2300).

  • Combine multiple techniques in unfamiliar problems; identify approaches from constraints.
  • Advanced DP, graph theory, trees, flows/matching and data-structure techniques as needed.
  • Deeper combinatorics, probability, algebraic ideas and proof-driven problem solving.
  • Optimise implementation speed, debugging discipline and contest decisions.
  • Review rating swings and recurring weaknesses instead of chasing volume alone.

Practice: 1700–2400+ problems selected for gaps. Use virtual contests, difficult upsolves and deliberate revision.

PHASE 062400+

Grandmaster · red

Target: peak rating of at least 2400.

  • Maintain performance across varied rounds, not only familiar topic sets.
  • Continue closing gaps in advanced algorithms, mathematics and constructive reasoning.
  • Protect accuracy: choose problems strategically, validate edge cases and avoid preventable penalties.

Standard: 2400 peak rating is the Grandmaster threshold. This is a demanding long-term goal, not a fixed-duration promise.

WEEKLY TRAINING LOOP

Repeat this cycle

  1. Learn (2 sessions): study one concept, derive when it applies, and implement only after understanding it.
  2. Focused practice (2 sessions): solve 3–5 problems around that concept, increasing difficulty gradually.
  3. Contest (1–2 sessions): take a rated round when available or a 2-hour virtual contest.
  4. Upsolve (1–2 sessions): finish missed problems, write the key observation and code again from a blank editor.
  5. Review (weekly): classify errors as knowledge, observation, proof, implementation or time management.
CONTEST METHOD

How to use each round

  1. Scan all problems and identify the easiest reliable points first.
  2. Set a time limit for a stalled approach; switch when progress stops.
  3. Test minimum, maximum, duplicate, sorted/reversed and overflow cases before submitting.
  4. After the round, upsolve without looking at code first; use hints/editorials only after a serious attempt.
  5. Record one concrete correction for the next contest.
CORE RESOURCES

Study and practice

  • Codeforces Problemset — filter by rating and tags.
  • CP-Algorithms — reference for standard algorithms and data structures.
  • CSES Problem Set — structured core-algorithm practice.
  • USACO Guide — guided explanations and topic progression.
PROGRESS METRICS

Track ability, not just volume

  • Problems solved independently by rating band and topic.
  • Upsolve completion within 48 hours of a contest.
  • Accuracy and time-to-solve on familiar problem types.
  • Recurring error categories and which ones disappear.
  • Contest performance trend over several rounds; ignore single-round noise.

A useful weekly target is 12–20 carefully reviewed problems plus one contest and its upsolves. Adjust down when concepts are new; retention matters more than raw counts.

This roadmap is a skill sequence, not a promise that each rating band will take a set number of weeks. Advance when performance is repeatable. If your current rating is below 1200, begin with Phase 01 even if some topics feel familiar.
