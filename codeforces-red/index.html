WEEKLY EXECUTION

Daily training routine

A repeatable two-hour weekday template. Protect the independent attempt and editorial review rather than rushing through more problems.

60–75 min · Problem solvingAttempt two problems around 100–200 rating points above your current peak. Give each 30–40 minutes independently.
20–30 min · UpsolvingRevisit yesterday’s unsolved problems. Read the editorial only after a serious attempt, then close it and re-derive the solution.
20–30 min · Topic studyStudy one focused topic from the current stage using its linked chapter/reference, then solve a related problem.
Weekly · Contest + reviewTake one live or virtual contest and upsolve missed problems within 24 hours. Record why each attempt failed.

Foundation pass

Ch. 1 — Introduction (pp. 3–16): 1.1 Programming languages; 1.2 Input and output; 1.3 Working with numbers; 1.4 Shortening code; 1.5 Mathematics; 1.6 Contests and resources.

Ch. 2 — Time complexity (pp. 17–24): 2.1 Calculation rules; 2.2 Complexity classes; 2.3 Estimating efficiency; 2.4 Maximum subarray sum.

Ch. 3 — Sorting: 3.1 Sorting theory (p. 25); 3.2 Sorting in C++ (p. 29).

Ch. 4 — Data structures (first pass): 4.1 Dynamic arrays (p. 35); 4.2 Set structures (p. 37); 4.3 Map structures (p. 38).

Ch. 5 — Complete search (pp. 47–56): 5.1 Generating subsets; 5.2 Generating permutations; 5.3 Backtracking; 5.4 Pruning the search; 5.5 Meet in the middle.

Ch. 6 — Greedy algorithms (pp. 57–64): 6.1 Coin problem; 6.2 Scheduling; 6.3 Tasks and deadlines; 6.4 Minimizing sums; 6.5 Data compression.

Ch. 8 — Amortized analysis (pp. 77–82): 8.1 Two pointers method; 8.2 Nearest smaller elements; 8.3 Sliding window minimum.

Specialist pass

Ch. 3 — Sorting: 3.3 Binary search (p. 31).

Ch. 4 — Data structures (second pass): 4.4 Iterators and ranges (p. 39); 4.5 Other structures (p. 41); 4.6 Comparison to sorting (p. 44). Revisit set/map operations from 4.2–4.3 when solving problems that need ordered lookup or updates.

Ch. 9 — Range queries (pp. 83–94): 9.1 Static array queries; 9.2 Binary indexed tree; 9.3 Segment tree; 9.4 Additional techniques.

Ch. 21 — Number theory (pp. 197–206): 21.1 Primes and factors; 21.2 Modular arithmetic; 21.3 Solving equations; 21.4 Other results.

Ch. 22 — Combinatorics (pp. 207–216): 22.1 Binomial coefficients; 22.2 Catalan numbers; 22.3 Inclusion-exclusion; 22.4 Burnside’s lemma; 22.5 Cayley’s formula.
